==============================================================
   FC온라인 감독모드 매크로  사용법  (v3.2)
==============================================================

  자세한 기능 설명이 필요하면 제작자에게 물어봐 주세요.
  이 파일은 "처음 쓰는 사람"이 바로 따라 할 수 있게 정리한 것입니다.


──────────────────────────────────────────────
 1. 처음 한 번만 하면 되는 준비
──────────────────────────────────────────────

 ① 게임 화면 설정
    FC온라인 설정에서  [창모드]  +  [1280 x 720]  으로 바꿔 주세요.
    (다른 크기면 매크로가 버튼을 못 찾습니다)

 ② 매크로를 켜면 뜨는 Windows 확인 창에서 [예]   ★ 가장 중요 ★
    "이 앱이 디바이스를 변경하도록 허용하시겠어요?" → [예]
    매크로가 스스로 관리자 권한으로 다시 켜지는 과정입니다. (켤 때마다 한 번씩 뜸)
    [아니요]를 누르면 화면은 다 알아보는데 게임이 클릭을 무시해서 아무것도 안 눌립니다.
    (게임이 관리자 권한으로 돌아가서, 매크로도 같은 권한이어야 클릭이 들어갑니다)

 ③ 창 위치 정리
    게임 창과 매크로 창이 서로 겹치지 않게 나란히 두세요.
    (매크로는 게임 화면을 "보고" 누르기 때문에, 가려지면 못 누릅니다)
    자리를 잡았으면 매크로 창 맨 위 오른쪽의 [▣ 배치 저장]을 한 번 누르세요.
    → 다음부터 켤 때마다 그 자리로 알아서 옮겨 줍니다.

 ④ (선택) 휴대폰 알림 받기
    밖에서도 진행 상황을 보고 싶으면 아래 "6. 휴대폰으로 보기"를 따라 하세요.


──────────────────────────────────────────────
 2. 매일 쓰는 방법 (이것만 알면 됩니다)
──────────────────────────────────────────────

  1) FC온라인을 켜고 감독모드 공식경기 화면까지 들어가기
  2) fifa_macro.exe 실행
     → "새 버전이 있습니다. 업데이트할까요?" 가 뜨면 [예]
  3) 매크로 창에서 [▶ 시작] (또는 F9)
  4) 설정창이 뜨면 원하는 것만 채우고 [시작]
     - 목표 점수 / 목표 순위 : 여기까지 오르면 알아서 멈춤 (비워두면 계속)
     - 종료 시각 : 예) 07:00 → 그 시각 이후엔 새 판을 안 하고 멈춤
     - 나머지는 비워둬도 됩니다
  5) 끝! 이제 매크로가 알아서 경기를 돌리고 매판 기록합니다.

  ※ 시작 직후 매크로 창 아래 [알림·점검]에 빨간 ✖ 가 있으면 그것부터 해결하세요.


──────────────────────────────────────────────
 3. 매크로 창 버튼
──────────────────────────────────────────────

   [◎ 항상 위]  F6   매크로 창을 항상 맨 위에 (게임을 가리지 않게 주의)
   [✔ 점검]     F7   지금 잘 돌아갈 수 있는 상태인지 검사
   [⚙ 설정]     F8   목표 점수·종료 시각·알림 등 바꾸기

   [▶ 시작]     F9   자동진행 시작
   [❚❚ 일시정지] F10  잠깐 멈춤 (다시 누르면 이어서 진행)
                      → 직접 이적시장을 보거나 할 때 누르세요
   [↗ 차트]     F11  지금까지 기록 그래프 (인터넷 창으로 열림)

   [■ 종료]     F12  바로 멈춤 (경기 중이면 그 판은 패배될 수 있음)
   [⚑ 막판종료] Ctrl+F12  이번 판까지만 하고 끝내기 (아래 4번)
   [⇄ 전술 자동 변경]     승률이 떨어지면 전술을 알아서 바꾸기 (아래 5번)

   [⌨ 단축키 설정]        단축키를 원하는 키로 바꾸기
   [☰ 오늘 결산]          오늘 몇 판·몇 승 했는지
   [⚔ 포메이션·전술]      상대 포메이션별 · 내 전술별 승률
   맨 위 [▣ 배치 저장]     지금 창 위치 기억하기 (자주 안 쓰는 기능이라 위로 옮김)

   - '흐름' 칸 = 최근 20판 (왼쪽이 오래된 판, 오른쪽 끝이 방금 끝난 판)
   - 랭킹점수 오른쪽 그림 = 지금 티어 (로비를 한 번 지나면 게임 화면에서 가져와 보여줌)
   - '승강전' 칸 (챔피언스 아래 티어일 때만): 10판 승점 막대
       파란 막대 = 지금 승점 (승 3 · 무 1 · 패 0)   주황 선 = 잔류선 (이 아래로 끝나면 강등)
       초록 선 = 승급선 (닿는 순간 승급)          흰 선 = 남은 판을 다 이기면 받을 수 있는 최대
     "다음 판 이기면 승급", "다음 판 지면 강등 확정" 같은 갈림길은 휴대폰으로도 알려 줍니다.
   - 창 맨 아래 기록 폴더 경로를 누르면 기록 폴더가 열립니다.
   - 단축키는 게임 화면을 보고 있을 때도 그대로 먹힙니다.
   - 예전 검은 글자 창이 더 편하면: 설정(F8) 맨 아래 '버튼식 매크로 창 쓰기' 체크 해제


──────────────────────────────────────────────
 4. 막판종료 - 밖에 나가야 할 때
──────────────────────────────────────────────

  경기 중간에 게임을 끄면 패배 처리되죠. 막판종료를 쓰면:
   ① 지금 하고 있는 판은 끝까지 하고
   ② 로비로 돌아오면 다음 판을 시작하지 않고 매크로가 멈추고
   ③ 게임 창까지 닫아 준 뒤
   ④ 휴대폰으로 "막판종료 완료" 알림을 보내 줍니다.

  누르는 곳:  매크로 창 [⚑ 막판종료]  /  Ctrl+F12  /  텔레그램 🏁 막판종료 (밖에서도 가능)
  취소하려면 한 번 더 누르면 됩니다.


──────────────────────────────────────────────
 5. 전술 자동 변경 - 승률이 떨어지면 전술 바꾸기
──────────────────────────────────────────────

  게임 스쿼드 화면(경기 전 [진행] 버튼 있는 화면)의 [전술 ▼] 목록에서
  미리 고른 전술(최대 3개)을 기준에 따라 번갈아 씁니다.

 [등록] (전술마다 한 번)
   1) 매크로 창 [⇄ 전술 자동 변경] → ①칸의 [+ 전술 등록]  (매크로는 잠깐 일시정지됨)
   2) 게임 스쿼드 화면에서 [전술 ▼] 목록을 열고, 쓸 전술을 마우스로 클릭
   3) 등록 완료! ②, ③도 같은 방법으로 (2개 이상 등록해야 바뀝니다)
   ※ 게임에서 전술 목록 순서를 바꾸거나 이름을 바꾸면 [다시 등록]을 눌러 주세요

 [바꾸는 기준] (창에서 숫자를 직접 바꿀 수 있음)
   - 최근 30판 승률이 40% 미만이면 다음 전술로 (한 전술로 30판을 채운 뒤부터 판단)
   - 6연패면 판수와 상관없이 바로 다음 전술로 (끌 수 있음)
   - 모든 전술이 기준 미만이면 그중 승률이 가장 좋았던 전술로 고정
       → 100판이 지나면 처음부터 다시 평가
       → 고정 중에 연패하면: '알림만' 또는 '고정 풀고 다음 전술로' 중 고르기
   - 순서: ① → ② → ③ → ① … (등록한 전술만)

 [알아 두기]
   - 바꿀 때는 경기 전 스쿼드 화면에서 바꾸고, 바뀐 걸 확인한 뒤 [진행]을 누릅니다.
   - 연속 진행 중에는 스쿼드 화면을 안 거쳐서 바꾸지 않고, 연속 진행이 끝난 뒤 바꿉니다.
   - 게임에서 등록 안 한 전술로 직접 바꿔 두면 자동 변경을 멈추고 그대로 진행합니다.
     (등록한 전술로 돌려 놓으면 다시 작동)
   - 전술을 못 바꾸면 원래 전술 그대로 진행하고 휴대폰으로 알려 줍니다. (엉뚱한 전술로 진행하지 않음)
   - 창의 [지금 이걸로] 또는 텔레그램 ⇄ 전술 버튼으로 직접 바꿀 수도 있어요 (다음 판부터).
   - 매 판 어떤 전술로 했는지 기록되고, [⚔ 포메이션·전술]과 차트(F11)에서 전술별 승률을 볼 수 있어요.


──────────────────────────────────────────────
 6. 휴대폰으로 보기 (선택)
──────────────────────────────────────────────

  텔레그램 또는 디스코드 중 편한 것 하나만 해도 됩니다. (추천: 텔레그램 - 버튼으로 조작 가능)

 [텔레그램]  5분이면 끝
   1) 텔레그램에서 @BotFather 검색 → 대화 시작 → /newbot 입력
   2) 봇 이름 아무거나 → 봇 아이디 입력 (영어, 끝이 bot 으로 끝나야 함. 예: chulsoo_fc_bot)
   3) BotFather가 보내준 긴 토큰(123456789:AAH... 처럼 생김)을 복사
      ※ 이 토큰은 남에게 절대 보여주지 마세요
   4) 매크로 [⚙ 설정] → '텔레그램' 칸에 붙여넣기 → [저장]
   5) 텔레그램에서 방금 만든 내 봇을 열고 [시작] 누르기
   6) 설정창 [테스트] → 텔레그램에 메시지가 오면 성공

   이제 텔레그램 아래 버튼으로 할 수 있는 것:
    📋 상태(게임 화면 사진)  📈 차트  📅 오늘 결산  ⚔ 포메이션  ⇄ 전술
    ❚❚ 일시정지  ▶ 재개  ⏹ 종료  🏁 막판종료  ⚙ 설정
   ⇄ 전술: 지금 전술·전술별 승률 + [① ② ③] 버튼으로 다음 판 전술 바꾸기, 자동 변경 켜기·끄기
   ※ 봇은 각자 하나씩 만들어야 합니다. (다른 사람 봇을 같이 쓰면 오류)

 [디스코드]  알림만 받을 때
   1) 디스코드 내 서버의 채널 → 채널 편집(톱니바퀴) → 연동 → 웹후크 → [새 웹후크]
   2) [웹후크 URL 복사]
   3) 매크로 [⚙ 설정] → '디스코드 웹훅' 칸에 붙여넣기 → [테스트 전송]

  이럴 때 알림이 옵니다:
   목표 도달로 멈춤 / 승급·강등 / 게임이 멈춘 것 같을 때 / 게임 창이 꺼졌을 때 / 막판종료 완료
   승강전 갈림길 (다음 판 이기면 승급 · 다음 판 지면 강등 확정 · 결과) / 전술 변경
   (설정에서 '하루 결산'을 켜면 매일 자정에 하루 요약도 옴)


──────────────────────────────────────────────
 7. 원격 PC방(리피시)으로 돌릴 때
──────────────────────────────────────────────

  매크로는 "집 컴퓨터"에서 켜고, 게임은 원격 PC 안에서 돌아가는 방식도 됩니다.
  따로 켜는 설정은 없고, 아래만 지키면 매크로가 알아서 '원격 모드'로 바뀝니다.
   - 원격 프로그램은 전체화면, 내 모니터 해상도 그대로 (작게 줄여 보이면 안 됨)
   - 원격 PC 게임도 창모드 1280x720, 게임 창 맨 위 'FC ONLINE' 글씨가 보이게
   - 원격 PC 오른쪽 아래 입력 상태를 'A'(영문)로
   - 매크로 창이 원격 화면 속 게임을 가리지 않게
  ※ 원격 모드에서는 막판종료가 "매크로 정지"까지만 됩니다 (원격 PC 게임은 직접 끄기)


──────────────────────────────────────────────
 8. 이럴 땐 이렇게 (문제 해결)
──────────────────────────────────────────────

  Q. 화면은 알아보는데 클릭을 아예 안 해요 / 같은 버튼만 계속 눌러요
  A. 관리자 권한이 아니어서 그렇습니다. 매크로를 끄고 다시 켠 뒤 Windows 확인 창에서 [예]를 눌러 주세요.
     (매크로 창 상태 칸에 "관리자 권한이 아니에요"가 떠 있으면 이 경우입니다)

  Q. 아무 반응이 없어요
  A. [✔ 점검](F7)을 누르고 빨간 ✖ 항목을 확인하세요.
     대부분 ① 게임이 1280x720 창모드가 아님  ② 매크로 창이 게임을 가림  ③ 관리자 권한 아님

  Q. 점수나 순위가 빈칸으로 기록돼요 / 포메이션이 '미인식'이에요
  A. 기록 폴더의 rank_samples 또는 formation_samples 폴더를 압축해서 제작자에게 보내 주세요.
     (포메이션 숫자는 경기를 하면서 조금씩 스스로 배우기도 합니다)

  Q. 매크로 창에 '오류 발생'이 떠요
  A. 기록 폴더의 macro.log 파일을 제작자에게 보내 주세요.

  Q. 백신이나 Windows가 경고를 띄워요
  A. 직접 만든 프로그램이라 뜰 수 있습니다. [추가 정보] → [실행]

  Q. 텔레그램 테스트가 실패해요
  A. "토큰이 틀림" → BotFather에서 토큰을 다시 복사
     "/start 를 보낸 뒤" → 내 봇 대화방에서 [시작]을 먼저 누르기

  Q. 매크로를 다시 켜면 기록이 사라지나요?
  A. 아니요. 기록은 '문서\FC매크로_기록' 폴더에 따로 저장되고, 매일 자동 백업도 됩니다.
     exe를 새로 받아도 그대로 이어집니다.
