■ 실행 전 준비
  1. FC온라인을 [창모드 1280 x 720]으로 실행하세요.
  2. fifa_macro.exe 하나만 있으면 됩니다 (코드·버튼/숫자 이미지는 exe 안에 들어 있음).
     새 버전은 켤 때 자동으로 알려줍니다 (아래 '자동 업데이트'). exe를 다시 받을 필요가 거의 없습니다.
  3. 매크로 창(검은 창)이 게임 창을 가리지 않게 옆이나 아래에 두세요.
     (매크로는 화면을 보고 버튼을 찾기 때문에 가려지면 오작동합니다)
  4. 잘 안 되면 Windows 디스플레이 배율을 100%로 맞춰 보세요.

■ 자동 업데이트 (v2.0부터)
  매크로를 켤 때 새 버전이 있으면 창이 뜹니다:  "새 버전 v2.1 이 있습니다 … 지금 업데이트할까요?"
   [예]     → 새 코드만 받아서(1MB 미만) 바로 그 버전으로 실행. 자동진행 시작 전(대기 상태)에만 적용됩니다.
   [아니오] → 지금 버전으로 실행 (다음에 켤 때 다시 물어봄)
  안전장치
   - 받은 파일이 깨졌으면(검증값 불일치) 설치하지 않음
   - 새 버전이 켜지다가 오류가 나면 직전 버전으로 자동 복귀하고 다시 켬 (그 버전은 다시 묻지 않음)
   - 기록·설정·견본(기록 폴더)은 업데이트와 상관없이 그대로
  받은 코드 위치: 기록 폴더\app\current (직전 버전은 app\previous)  /  업데이트 기록: 기록 폴더\update.log
  가끔 "실행기(fifa_macro.exe)를 새로 받아야 합니다" 가 뜨면 제작자에게 새 exe를 받으세요 (라이브러리가 바뀐 경우).

  [처음 한 번]
   1. https://github.com 에서 가입 (무료)
   2. 오른쪽 위 [+] → [New repository]
      · Repository name: fcmacro-update   · Public 선택 (친구들이 로그인 없이 받으려면 공개여야 함)
      · 'Add a README file' 체크 → [Create repository]
   3. 내 업데이트 주소 = https://raw.githubusercontent.com/내아이디/fcmacro-update/main/
      (내아이디 = GitHub 아이디, 저장소 이름을 바꿨으면 그 이름)
   4. 소스 폴더의 code\update_url.txt 를 메모장으로 열어 맨 아래 빈 줄에 3번 주소를 붙여넣고 저장
   5. build_exe.bat 실행 → 새 fifa_macro.exe 를 친구들에게 '한 번만' 보내기 (이 exe에 주소가 들어감)
   6. 받은 '깃허브_업로드' 폴더의 version.json, fcmacro_code.zip 두 파일을 아래 [업데이트할 때] 방법으로 올리기
  [업데이트할 때마다] (빌드 필요 없음)
   1. 제작자(Claude)에게 받은 '깃허브_업로드' 폴더의 두 파일: version.json, fcmacro_code.zip
   2. GitHub 저장소 페이지 → [Add file] → [Upload files] → 두 파일을 끌어다 놓기
   3. 아래 [Commit changes] 클릭 (같은 이름이면 자동으로 덮어씀)
   4. 끝. 친구들이 매크로를 켜면 '업데이트할까요?' 창이 뜸 (올린 뒤 몇 분 걸릴 수 있음 - GitHub 캐시)
  [주의]
   - 공개 저장소라 코드가 누구나 볼 수 있음 (웹훅 주소·봇 토큰·기록은 각자 PC에만 있어서 올라가지 않음)
   - version.json 과 fcmacro_code.zip 은 반드시 같이 올리기 (검증값이 서로 맞아야 설치됨)
   - 내 PC에서 확인: 매크로 켰을 때 창이 뜨는지 / 기록 폴더\update.log

■ 단축키
  F6  : 매크로 창 항상 위 켜기/끄기 (설정 저장됨, 트레이 메뉴에서도 가능)
        ※ 항상 위로 둔 매크로 창이 게임 창을 가리면 버튼 인식이 안 됩니다.
          켤 때 겹침을 자동 점검하니, 경고가 뜨면 매크로 창을 게임 옆으로 옮겨 주세요.
  F7  : 점검 / 화면 인식 테스트
        - 게임 창 크기, 매크로 창 겹침, 이미지 상태를 ✔/✖로 보여줍니다
        - 홈 화면에서 누르면 랭킹점수(챔스) / 티어 화면 종류, VS 화면에서 누르면 점수·순위를 읽어 봅니다
        - 경기 전 라인업 화면(오른쪽 아래 '포메이션')에서 누르면 포메이션을 읽어 봅니다
        - 매크로를 켜면 한 번 자동으로 점검합니다
  F8  : 설정 변경
        - 진행 중: [적용] → 기록은 그대로 이어지고 정지 조건·웹훅만 바뀜
        - 멈춰 있을 때: [저장] → 다음에 F9로 시작할 때 사용
  F9  : 자동진행 시작 → 설정창이 뜨고 [시작]
        - 모든 티어(배치 경기 포함)를 진행하면서 매판 기록
        - 이미 진행 중이면 눌러도 무시됩니다 (기록 초기화 방지)
  F10 : 일시정지 / 재개 (누르는 즉시)
        - 버튼 클릭과 S키 입력을 모두 멈춥니다 (게임 중 이적시장 검색 등)
        - 다시 누르면 기록·통계가 그대로 이어지면서 재개
  F11 : 기록 차트 열기 (브라우저)
  F12 : 자동진행 종료

■ 설정창 (F9 시작 / F8 변경) - 모두 선택, 비워두면 그 조건 없음
  - 목표 점수 : 챔스 랭킹점수가 이 점수 이상이면 공식경기를 누르지 않고 멈춤
  - 목표 순위 : 순위가 이 순위 이내면 멈춤 (예: 20 → 슈퍼 챔피언스 주차)
                ※ 순위는 VS 화면에서 읽으므로, 그 판이 끝나고 다음 홈 화면에서 멈춤
  - 챔스 승급 대기 (체크) : 슈퍼챌린저에서 '다음 판을 이기면 챔피언스 승급'인 상태가 되면 멈추고,
                자정(00:00:30)이 지나면 자동으로 다시 진행 → 자정 직후 챔스에 올라가 하루 종일 강등 보호
                · 승점 막대에서 현재 승점(결과 칸 승×3 + 무×1)이 초록 선(승격선)까지 3점 이내면 멈춤
                  (초록 선을 못 읽으면 12점으로 보고 일찍 멈춤)
                · 이미 0시대(00:00~00:59)면 기다리지 않고 바로 진행
                · 슈퍼챌린저 티어 이름이 등록돼 있어야 함 (아래 '티어 이름 등록')
  - 연패 경고 : 예) 5 → 5연패하면 디스코드·텔레그램 알림 (같은 연패는 한 번만) · '일시정지도' 체크하면 그때 일시정지
                (다시 진행: F10 또는 디스코드 !재개 / 텔레그램 ▶ 재개)
  - 하루 결산 리포트 (체크) : 매일 자정에 전날 판수·승무패·점수 변화·순위·승급/강등·최장 연승/연패 + 그래프 전송
                (켠 날 밤 자정부터 보냄 · 매크로 프로그램이 켜져 있어야 함)
  - 시작 시각 : 예) 00:05 → 그 시각이 되면 자동으로 시작 (비우면 바로 시작)
  - 종료 시각 : 예) 07:00 → 컴퓨터 시계로 그 시각 이후엔 새 판을 시작하지 않고 정지
                (진행 중인 경기는 끝까지 함)
  - 디스코드 웹훅 : 알림 받을 주소 (비워두면 알림 없음) → [테스트 전송]으로 확인
  - 텔레그램 봇 토큰 : 텔레그램으로 알림·명령 (아래 '텔레그램 알림') → [테스트]로 확인
    ※ 디스코드와 텔레그램은 둘 중 하나만 써도 되고 둘 다 써도 됩니다 (알림이 양쪽으로 감)
  - Enter = 시작/적용/저장, Esc = 취소
  ※ 목표 점수·순위, 웹훅 주소는 저장되어 다음에도 그대로 나옵니다. 종료 시각은 매번 새로 입력합니다.
  ※ 정지 조건은 홈 화면에서 공식경기를 누르기 직전에 확인합니다.

■ 무엇이 기록되나 (매판)
  - 챔스 : 홈 화면의 랭킹점수 + VS 화면의 순위
  - 챔스 아래 티어 : VS 화면의 점수 (홈 화면에는 점수가 없어서)
  - 승/무/패 : 챔스 아래 티어는 화면의 최근 결과 칸 색, 챔스는 다음 판 점수와 비교
              (점수가 그대로면 무승부 - 상대가 챔스가 아니면 승부차기 없이 비길 수 있음)
  - 포메이션 : 경기 전 라인업 화면의 상대 포메이션 / 내 포메이션 (아래 '포메이션 기록')
  - 승급 / 강등 : 홈 화면의 티어 이름이 바뀌면 방금 끝난 판에 ▲승급 / ▼강등 표시
    (방향을 알 수 없으면 ◆티어 변경으로 표시)

■ 티어 이름 등록 (한 번만 하면 됨)
  처음 보는 티어가 나오면 기록 폴더\tier_samples 에 '이름없음_날짜시간.png' 가 저장됩니다.
  그 파일 이름을 티어 이름으로 바꿔 두세요.  예) 마스터 3부.png / 월드클래스 1부.png / 챔피언스.png
  → 다음 판부터 매크로 창에 현재 티어가 표시되고, 티어가 바뀔 때 승급/강등 방향도 이름으로 정확히 판단합니다.
  ※ 바로 위/아래 티어로 바뀐 경우엔 매크로가 이름을 추정해서 '티어이름.png' 로 직접 저장하기도 합니다 (틀리면 이름을 고쳐 주세요).
  (티어 순서: 월드클래스 3부 < 2부 < 1부 < 마스터 3~1부 < 챌린저 3~1부 < 슈퍼챌린저 < 챔피언스)
  (파일 이름 예: 월드클래스 3부 / 마스터 1부 / 챌린저 2부 / 슈퍼챌린저 / 챔피언스)
  - 배치 경기 / 연속 진행 표시
  ※ 못 읽은 칸은 틀린 값 대신 빈칸으로 둡니다

■ 포메이션 기록 (v2.2)
  경기 전에 나오는 라인업 화면(오른쪽 아래 '포메이션  4-2-2-2')의 글씨를 읽어 매판 기록합니다.
   - 왼쪽에 '상대 기록'이 있는 화면 = 상대 팀, 없는 화면 = 내 팀
   - 따로 할 일 없음. 버튼도 누르지 않고 읽기만 합니다 (진행 속도 그대로)
   - 숫자 견본은 처음에 2·4만 들어 있고, 나머지 숫자(1·3·5 등)는 경기하면서 자동으로 배웁니다
     (포메이션 숫자의 합은 항상 10이라서, 예를 들어 4-3-3 을 보면 '3' 모양을 스스로 익힘)
     배운 견본: 기록 폴더\formation_digits  (틀리게 배운 것 같으면 그 폴더를 지우면 처음부터 다시 배움)
   - 그래도 못 읽은 판은 '미인식'으로 남고 글씨 부분이 기록 폴더\formation_samples 에 저장됩니다
     → 그 폴더를 제작자에게 보내면 견본을 추가해 드립니다
   - 결과 보기: F11 차트 '포메이션별 승률' (상대별 / 내 포메이션별 / 내 × 상대 조합)
                디스코드 !포메이션 (!포메이션 내) / 텔레그램 ⚔ 포메이션 · 하루 결산에도 상대 포메이션 요약

■ 텔레그램 알림 · 명령 (선택 · 휴대폰으로 받기)
  디스코드 대신(또는 같이) 텔레그램으로 알림을 받고, 버튼으로 매크로를 조작합니다.
  처음 한 번 설정:
   1. 텔레그램에서 @BotFather 검색 → 대화 시작 → /newbot
   2. 봇 이름(아무거나) → 봇 아이디(영문, 끝이 bot 으로 끝나야 함, 예: hs_fcmacro_bot) 입력
   3. BotFather가 보내준 토큰(예: 123456789:AAH...)을 복사   ※ 남에게 절대 공유 금지
   4. 매크로 설정창(F8)의 '텔레그램' 칸에 붙여넣기
   5. 텔레그램에서 방금 만든 내 봇을 열고 [시작](/start) 누르기
   6. 설정창에서 [테스트] → "전송 성공"이 뜨고 텔레그램에 테스트 메시지가 오면 끝 → [저장/적용]
      (설정을 먼저 저장했다면 5번만 해도 바로 연결됩니다)
  명령 (아래 버튼 / 왼쪽 아래 [메뉴] / 직접 입력 모두 가능, 한글로 쳐도 됨):
   📋 상태 /status      진행 상황 + 게임 화면       📈 차트 /chart        최근 기록 그래프
   📅 오늘 결산 /today   오늘 결산 · /yesterday 어제  ⚔ 포메이션 /formation  포메이션별 승률 (/formation 내)
   ⚙ 설정 /settings     설정 보기 · 바꾸기 (예: 설정 점수 4600, /settings 도움)
   ❚❚ 일시정지 /pause    ▶ 재개 /resume            ⏹ 종료 /stop (한 번 더 확인)   ❓ 도움 /help
  ※ 처음 /start 를 보낸 대화만 '주인'으로 등록됩니다. 다른 사람이 봇을 찾아도 명령·알림은 주인에게만.
  ※ 봇은 PC(사람)마다 따로 만드세요. 같은 봇을 두 PC에서 쓰면 "다른 곳에서 쓰는 중" 오류가 납니다.
  ※ 매크로를 켜기 전에 보낸 명령은 실행하지 않습니다 (예: 어젯밤에 보낸 종료가 오늘 실행되는 일 없음)

■ 디스코드 알림 설정 (휴대폰으로 받기)
  1. 디스코드에서 알림 받을 채널 → 채널 편집(톱니바퀴) → 연동 → 웹후크
  2. [새 웹후크] → [웹후크 URL 복사]
  3. 설정창(F9 또는 F8)의 '디스코드 웹훅' 칸에 붙여넣기 → [테스트 전송]
  4. 휴대폰 디스코드에서 그 채널 알림을 '모든 메시지'로 설정
  알림이 오는 경우:
   - 목표 점수·순위 도달(주차 완료) / 종료 시각으로 정지  → 점수·순위 그래프 이미지 첨부
   - 승급 / 강등
   - 점수 인식 실패로 정지                              → 게임 화면 캡처 첨부
   - 멈춤 감지: 게임 화면이 10분째 그대로 / 30분 넘게 새 판 없음 → 게임 화면 캡처 첨부
   - 게임 창 사라짐 / 연속 진행 감지
  ※ 웹훅 주소를 아는 사람은 누구나 그 채널에 글을 쓸 수 있으니 남에게 공유하지 마세요.

■ 디스코드 봇 (디스코드에서 매크로 조작 · 선택)
  알림 채널에 명령을 치면 매크로가 답합니다. (PC가 켜져 있고 매크로가 실행 중이어야 함)
   !상태  지금 진행 상황 + 게임 화면 캡처      !차트  최근 기록 그래프
   !정지  일시정지 (F10)    !재개  다시 진행    !종료  자동진행 종료 (F12)    !도움  명령 목록
   !결산  오늘 결산(지금까지) · !결산 어제
   !설정  지금 설정 보기 · 바꾸기 예) !설정 점수 4600 / !설정 순위 20 / !설정 종료 07:00 / !설정 연패 5
          !설정 연패정지 켜기 / !설정 대기 켜기 / !설정 결산 켜기   (없음·끄기 로 해제, !설정 도움)
  처음 한 번 설정:
   1. https://discord.com/developers/applications → [New Application] → 이름 입력 → 만들기
   2. 왼쪽 [Bot] → [Reset Token] → 토큰 복사 (남에게 절대 공유 금지)
   3. 같은 [Bot] 화면 아래 'MESSAGE CONTENT INTENT' 켜기 → [Save Changes]   ※ 이걸 안 켜면 명령을 못 읽음
   4. 왼쪽 [OAuth2] → [URL Generator] → scopes: bot 체크 → 권한: View Channels, Send Messages,
      Read Message History, Attach Files, Embed Links 체크 → 아래 생긴 주소를 열어 내 서버에 초대
   5. 매크로 설정창(F8)의 '봇 토큰' 칸에 붙여넣기 → [저장]   (웹훅 주소도 있어야 함: 같은 채널을 씀)
   6. 알림 채널에 !등록 입력 → 이제 내 계정의 명령만 받습니다 (친구와 같은 채널이어도 안전)
   !포메이션  상대 포메이션별 승률 · !포메이션 내
  매크로 창의 '봇' 줄과 F7 점검에 연결 상태가 보입니다. 명령은 몇 초 안에 답합니다.

■ 이적시장 자동 닫기
  자동진행 중 이적시장 창이 떠 있으면 매크로는 다른 버튼을 누르지 않고 기다립니다.
  마우스·키보드 입력이 1분 동안 없으면(잠든 경우 등) 이적시장 X를 눌러 닫고 계속 진행합니다.
  (매크로가 한 클릭은 입력으로 안 셈 · 쓰는 중이면 닫지 않음 · 오래 볼 때는 F10 일시정지 추천)

■ 연속 진행
  매크로는 [진행] 버튼으로 한 판씩 진행합니다. 직접 [연속 진행]을 켜도 매판 VS 화면에서 기록은 남지만,
  홈 화면을 거치지 않아서 목표 점수·순위·종료 시각 정지가 되지 않습니다 (감지하면 노란 경고 + 알림).

■ 작업표시줄 / 트레이 아이콘
  - 매크로 창 제목에 현재 상태가 보입니다 (작업표시줄에 마우스만 올려도 확인)
  - 오른쪽 아래 트레이에 아이콘이 생기고 점 색으로 상태 표시
    (초록=진행 중, 노랑=경고·일시정지, 빨강=정지, 회색=대기)
  - 트레이 아이콘 우클릭: 기록 차트 / 기록 폴더 / 일시정지 / 자동진행 종료 / 항상 위 / 매크로 종료

■ 매크로 창에 보이는 정보
  - 상태 : 초록=진행 중 / 노랑=경고·일시정지 / 빨강=정지
  - 정지 조건 : 지금 설정된 조건
  - ⏳ 대기 중 : 시작 예약 / 챔스 승급 대기일 때 재개 시각과 남은 시간
  - 티어 : 현재 티어 이름 + 이번에 승급/강등한 횟수, 마지막 승급/강등 시각
  - 통계 : 이번에 돌린 판수, 승/무/패와 승률, 판당 평균 점수 변화, 판당 걸린 시간
  - 오늘 : 오늘 하루 누적 (판수, 승/무/패와 승률, 점수 변화, 승급/강등 횟수)
  - 흐름 : 오늘 최근 20판 결과 (승=초록, 무=노랑, 패=빨강) + 현재 연승/연패
  - FC : 챔피언스 1승당 15 FC → 이번에 번 FC · 오늘 번 FC (챔스 판의 결과가 정해질 때마다 바로 올라감)
  - 예상 : 목표 점수가 있으면 남은 판수와 시간 (4판 이상 하면 계산)
  - 최근 기록 : 판별 점수, 순위, 승/무/패, 상대 포메이션(vs 4-2-2-2), 승급/강등
  - 텔레 : 텔레그램 연결 상태 (텔레그램 토큰을 넣었을 때)

■ 기록 차트 (F11)
  - 초록 선 = 랭킹점수(왼쪽 눈금), 파란 선 = 순위(오른쪽 눈금)
  - ▲승급 / ▼강등 / ◆티어 변경 표시 (세로 점선)
  - 그래프 위에 마우스를 올리면 그 판의 점수·순위·승급/강등이 보입니다
  - 위쪽 칸에 숫자를 넣으면 최근 N판만 볼 수 있습니다 / 길면 가로 스크롤(마우스 휠)
  - 아래에 날짜별 요약(판수, 승무패, 점수·순위 변화, 승급/강등)과 판별 기록 표
  - 패턴 분석: 세션 몇 판째 구간별 승률 / 연패·연승 직후 다음 판 승률 / 시간대·요일별 승률 / 최장 연승·연패
    (전체 승률보다 5%p 넘게 낮으면 빨간 막대, 10판 미만은 흐리게 = 참고만)
  - 포메이션별 승률: 상대 포메이션별 / 내 포메이션별 / 내 × 상대 조합(3판 이상) - 5판 미만은 흐리게
  - 판별 기록 표와 마우스 정보에 그 판의 포메이션

  백업 폴더            : ranking_log.csv 날짜별 백업
  rank_samples 폴더    : VS 화면에서 점수·순위를 못 읽은 판의 이미지 (제작자에게 보내면 인식 개선)

  formation_samples    : 포메이션을 못 읽은 판의 글씨 이미지 (제작자에게 보내면 인식 개선)

■ 문제 해결
  - 아무 반응이 없음 : F7 점검 결과의 ✖ 항목부터 확인 (창모드 1280x720, 매크로 창 겹침)
  - 매크로 창에 '오류 발생 - macro.log 참고' : macro.log 를 제작자에게 전달
  - "인식 실패"로 멈춤 : 다른 창이 게임 화면을 가리지 않았는지 확인
  - 점수·순위가 빈칸으로 기록됨 : rank_samples 폴더를 압축해서 제작자에게 전달
  - 버튼을 너무 빨리 눌러서 씹히는 것 같음 : 제작자에게 알려주세요 (속도 조절 가능)
  - 디스코드 테스트 실패 : 웹훅 주소를 다시 복사 (웹훅을 지우면 주소가 무효가 됨)
  - 텔레그램 테스트 실패 : "토큰이 틀림" → BotFather에서 토큰 다시 복사 / "/start 를 보낸 뒤" → 내 봇에게 /start
  - 포메이션이 '미인식'으로만 나옴 : formation_samples 폴더를 압축해서 제작자에게 전달
  - 매크로 창 글자가 깨지거나 이상한 기호가 보임 : Windows 10 이상에서 실행
  - 백신/Windows 경고 : 직접 만든 프로그램이라 뜰 수 있습니다
  - 매크로 실행 중에는 다른 프로그램에서 F11(전체화면)이 동작하지 않습니다
